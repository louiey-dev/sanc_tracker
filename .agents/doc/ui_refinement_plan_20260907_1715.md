# UI/UX 정밀 고도화 및 사용성 개선 계획 (2026-09-07)

## 1. 개요 및 목표

사용자 피드백 및 UI 리뷰에서 지적된 6가지 사용성 개선 요구사항을 체계적으로 반영한다.
기존의 4탭 아키텍처와 상태 격리(`route` vs `savedRoute`)를 온전히 보존하면서, 작은 화면에서의 지도 가시성을 극대화하고, 시각적 정보 위계를 강화하며, 추적 준비 상태를 명확히 안내한다.

---

## 2. 6대 세부 개선 항목

### 2.1. 지도 화면 및 HUD 밀도 최적화 (Point 1 & Point 2)

- **HUD 기본 접힘 모드**:
  - `TrackingHudCard`의 초기 상태를 접힘(`initiallyCollapsed: true`)으로 설정.
  - 대기 상태에서 지도 면적 85%+ 확보. 접힌 상태에서도 한 줄 요약과 원탭 `시작/중지` 지원.
  - 터치 시 3열 메트릭(시간/거리/속도) 부드러운 확장.
- **추적 전 준비 상태 안내 (Pre-tracking Readiness)**:
  - 위치 서비스 꺼짐, 권한 미승인, GPS 신호 수신 대기, 준비 완료 상태를 단계별로 안내.
  - GPS 미확보 시: *"GPS 위성 신호 대기 중 (실외 이동 권장)..."*
  - 준비 완료 시: *"GPS 준비 완료 (±{오차}m) · 시작을 누르면 기록됩니다"*

### 2.2. 기록 화면 시각화 고도화 (Point 3)

- **세션 카드 정보 위계 개선**:
  - 기존의 비구조화 줄글 텍스트를 구조화된 **시각적 메트릭스 뱃지/그리드**로 전환.
  - 헤더: 커스텀 이름(또는 날짜) + 상태 뱃지 (`완료` / `기록 중`).
  - 메트릭 칩: 거리 (`3.42 km`), 시간 (`1시간 25분`), 위치 수 (`124개 지점`).
  - 보조 정보: 시작 및 종료 시각.

### 2.3. 마커 화면 미디어 썸네일 표시 (Point 4)

- **마커 카드 미디어 썸네일**:
  - 사진/동영상 마커에 로컬 썸네일 이미지를 44x44 크기로 표시.
  - 동영상은 재생 아이콘 오버레이, 사진은 카메라 아이콘 오버레이 제공.
  - 일반 장소 마커는 기존 핀 아이콘 유지.

### 2.4. 설정 화면 가독성 및 백그라운드 안내 축소 (Point 5)

- **설명 축소 및 컴팩트화**:
  - 중복 문구를 제거하고 단일 아코디언 카드 그룹으로 집약.
  - 기본 화면 길이를 40% 이상 축소하여 핵심 설정(절전 모드, GPS 주기, 앱 권한) 즉시 노출.

### 2.5. 네비게이션 탭 상태 표시 (Point 6)

- **저장 경로 보기 중 상태 표시**:
  - `_isViewingSavedRoute` 상태 시 하단 `NavigationBar`의 `추적` 및 `기록` 탭에 뱃지 표시.
  - 지도 화면 상단에 전용 플로팅 배너 `[👁️ 저장 경로 보기 중: "{제목}" ({거리}km) | X 종료]` 제공.
